# مدى التسهيل للتجارة — موقع Landing Page

## وصف المشروع
موقع One Page عربي (RTL) تعريفي وتجاري لشركة مدى التسهيل للتجارة. يعرض الموقع فئات ومنتجات الشركة، ويتيح للزائر التواصل المباشر عبر واتساب لمعرفة التفاصيل والسعر والتوفر. الموقع مبني بالكامل بلغات الويب الأساسية (HTML, CSS, JavaScript) دون أي خادم (Backend) أو قاعدة بيانات أو نظام تسجيل دخول، مما يجعله خفيفًا وسهل التسليم والتعديل.

## رابط الموقع المنشور
https://madaltashilsa-hash.github.io/madaltashil/

## هيكل الملفات
- index.html — الصفحة الرئيسية وجميع الأقسام.
- style.css — تنسيقات وحركات الموقع بالكامل.
- app.js — بيانات المنتجات، منطق الفلاتر، نافذة تفاصيل المنتج، روابط واتساب، وحركات الظهور عند التمرير.
- assets/logo.png — شعار الشركة.
- README.md — هذا الملف.

## طريقة تشغيل المشروع محليًا
1. حمّل أو استنسخ (Clone) المستودع على جهازك.
2. افتح ملف index.html مباشرة في أي متصفح حديث.
3. لا حاجة لتثبيت أي برامج أو مكتبات، الموقع يعمل بدون إنترنت باستثناء تحميل الخط من Google Fonts.

## طريقة تعديل المنتجات والأسعار
جميع المنتجات موجودة في مكان واحد فقط داخل ملف app.js، في أعلى الملف ضمن المتغير باسم PRODUCTS.
كل منتج عبارة عن سطر بالشكل التالي، ويمكن نسخه وتعديله أو حذفه بسهولة:

id: رقم تسلسلي مميز للمنتج.
name: اسم المنتج الذي يظهر للزائر.
category: الفئة، ويجب أن تكون واحدة من: phones أو laptops أو accessories أو electronics.
icon: رمز تعبيري (إيموجي) يمثل المنتج بشكل مؤقت بدل الصورة.
price: السعر بالريال (رقم فقط بدون كتابة كلمة ريال).
available: true إذا كان المنتج متوفرًا، أو false إذا لم يكن متوفرًا.
desc: وصف قصير يظهر أسفل اسم المنتج.

لإضافة منتج جديد، انسخ سطر منتج موجود والصقه قبل علامة القوس المغلق للمصفوفة، ثم عدّل القيم.
لحذف منتج، احذف سطره بالكامل من المصفوفة.

## طريقة تعديل الصور
الموقع يستخدم حاليًا رموزًا تعبيرية (إيموجي) كبدائل مؤقتة لصور المنتجات لإبقاء المشروع خفيفًا وسريعًا. لاستخدام صور حقيقية:
1. أضف صور المنتجات داخل مجلد assets.
2. في ملف app.js استبدل قيمة icon للمنتج بوسم صورة، أو عدّل دالة renderProducts في app.js لعرض img بدل الرمز التعبيري حسب حاجتك.
لتغيير شعار الشركة، استبدل ملف assets/logo.png بنفس الاسم بصورة الشعار الجديدة (يفضل صيغة PNG بخلفية شفافة).

## طريقة النشر
الموقع منشور حاليًا عبر خدمة GitHub Pages مجانًا مباشرة من فرع main في المستودع. أي تعديل يتم حفظه (Commit) على فرع main في الملفات ينعكس تلقائيًا على الرابط المنشور خلال دقيقة إلى دقيقتين تقريبًا دون أي خطوة إضافية.

إذا رغب العميل بربط نطاق خاص (Domain) بالموقع مستقبلًا، يمكن ذلك من إعدادات GitHub Pages في المستودع (Settings ثم Pages) بإضافة النطاق المخصص هناك.
