# صور الفيديوهات التعريفية

الصور التي تعرضها الفيديوهات الأربعة في الصفحة الرئيسية.
المشغّل: `mt-video.js` + `mt-video.css` — الفيديو القديم `intro-video.html` تم حذفه.

## المواصفات

| البند | القيمة |
|---|---|
| مقاس الشاشات الكبيرة | `اسم.webp` — 1920×1080 (16:9) |
| مقاس الجوال | `اسم-m.webp` — 960×540 (16:9) |
| الصيغة | WebP · جودة 90 للديسكتوب و 88 للجوال |
| حجم الملف | 85 – 227 ك.ب للديسكتوب · ~50 ك.ب للجوال |
| الإجمالي | 28 صورة × نسختين = 5.5 ميجابايت |

الصور الأصلية كانت 3:2، ووُضعت كاملة داخل إطار 16:9 مع ملء الجوانب بنسخة
ضبابية من الصورة نفسها — بلا اقتصاص، فلا يُفقد أي نص أو شعار.
والمشغّل يستخدم `object-fit:contain` داخل مسرح 16:9، فالمحتوى يظهر كاملًا
على أي شاشة مهما كان مقاسها.

## الإخراج

| البند | القيمة |
|---|---|
| مدة المشهد | 8 ثوانٍ |
| الافتتاحية والختامية | 10 ثوانٍ لكل منهما (شعار + عبارة) |
| موضع النص | شريط مستقل **أسفل** الصورة — لا يغطّيها إطلاقًا |
| تأثيرات الانتقال | 5 تتناوب: `zoom` · `wipe` · `blur` · `slide` · `rise` |
| تأثيرات إضافية | وميض ضوئي يمرّ فوق الصورة · دخول متدرّج للنص · حلقتان متوسّعتان خلف الشعار |
| الإعادة | تلقائية بلا نهاية |
| شريط التقدّم | مقسّم — قطعة لكل مشهد |

## ملاحظة على صورة محذوفة

الصورة الأصلية الثانية لجهاز iPad Air 11" احتوت على خطأ في الشعار
(ظهر **AT** بدل **MT**)، فحُذفت ولم تُستخدم. البديل المعتمد هو
`ipad-air-11-m4-alt` وشعاره سليم.

## إضافة صورة جديدة

```bash
pip install pillow
python3 build/convert-video-images.py صورتك.png اسم-الصورة
```

السكربت يُنتج النسختين (`اسم.webp` و `اسم-m.webp`) في `assets/video/`.
بعدها أضف السطر في مصفوفة `scenes` داخل `mt-video.js`:

```js
['اسم-الصورة', 'التعليق الذي يظهر أسفل المشهد'],
```
