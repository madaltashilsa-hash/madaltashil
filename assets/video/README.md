# مجلد صور الفيديو التعريفي

هذا المجلد مخصّص لصور الفيديو التعريفي (`intro-video.html`).

ضع صورك هنا، وبعد رفعها نعدّل ملف الفيديو ليعرضها.

---

## قبل ما ترفع

الفيديو مكوّن من **9 مشاهد** بالترتيب التالي:

| # | المشهد |
|---|---|
| 1 | الشعار + «تسهيل اليوم .. نجاح الغد» |
| 2 | العلامات التجارية (Apple · Samsung · Huawei · Xiaomi …) |
| 3 | فئات المنتجات (جوالات · لابتوبات · أجهزة لوحية · ألعاب · ساعات · صوتيات) |
| 4 | مزايا الخدمة (ضمان الجودة · دعم واتساب) |
| 5 | الأرقام والإحصائيات |
| 6 | — |
| 7 | — |
| 8 | — |
| 9 | الخاتمة والتواصل |

---

## المقاس الموصى به

| البند | القيمة |
|---|---|
| الأبعاد | 1920×1080 بكسل (16:9) |
| الحد الأدنى | 1280×720 |
| حجم الملف | أقل من 300 كيلوبايت للصورة الواحدة |
| الصيغة الأفضل | WebP (أخف بنحو 80% من PNG بنفس الجودة) |

اجعل العنصر المهم في **وسط الصورة** — الحواف قد تُقتطع حسب مقاس الشاشة.

---

## لتحويل صورك إلى WebP

```bash
pip install pillow
python3 build/convert-banners.py صورتك.png scene-1
```

السكربت يُخرج الملفات في `assets/slides/` — انقل الناتج إلى هنا.

---

## بعد الرفع

أخبرني بأسماء الملفات التي رفعتها وأي مشهد تريد كل صورة فيه،
وأعدّل `intro-video.html` ليعرضها مع تأثير دخول وحجاب يضمن وضوح النص فوقها.

> هذا الملف موجود فقط لإنشاء المجلد على GitHub (لا يمكن رفع مجلد فارغ).
> يمكنك حذفه بعد إضافة الصور.
